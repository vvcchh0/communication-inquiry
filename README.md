# 人的表达与交流研究

通过持续会话探索交付给人的文本应如何使用语言、组织逻辑，以及如何支持理解与探索。始于 2026 年 11 月 1 日。

当前重点是直觉与思考讨论中的表达。后续逐渐涉及日常聊天、知识讲解、课题分析、自主研究的方法与成果报告。Agent 间通信保留为独立研究问题。

## 阅读入口

- [讨论共识](discussion-principles.md)：已确认的表达与组织原则，随讨论修订。
- [术语表](GLOSSARY.md)：当前采用的工作定义。
- [首轮讨论记录](sessions/2026-11-01.md)：问题如何展开、用户作了哪些修正。
- [待研究问题](open-questions.md)：尚未确定的解释与后续方向。
- [Agent 通信研究线索](research/agent-communication.md)：已查阅的来源与待验证问题。

## 记录方式

这是会话研究仓库。共识、假设和外部研究分别记录；摘要保留重要修正及其理由。会话记录为整理稿，原会话是完整上下文来源。术语与共识在得到确认后更新，新的推测先留在讨论或待研究问题中。

最初的术语表从工作区根目录 GLOSSARY.md 派生，原文件保留。后续本主题的术语维护在本仓库进行。仓库内容尚未写入全局 AGENTS.md。
