## 记录方式

这是会话研究仓库。共识、假设和外部研究分别记录；摘要保留重要修正及其理由。会话记录为整理稿，原会话是完整上下文来源。术语与共识在得到确认后更新，新的推测先留在讨论或待研究问题中。

最初的术语表从工作区根目录 GLOSSARY.md 派生，原文件保留。后续本主题的术语维护在本仓库进行。仓库内容尚未写入全局 AGENTS.md。

后续整合方向是形成可经全局 AGENTS.md 路由的参考预设。原则与案例分别维护，案例保留语境、修正和用途，支持跨项目理解与应用；具体路由和预设形式待后续讨论。
