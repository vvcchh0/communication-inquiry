## Question

怎样将讨论结果组织成可供全局 AGENTS.md 路由的参考预设，让模型按场景读取并利用原则与案例，同时持续吸收实际反馈？

决定入口、共享原则、场景材料、案例与研究假设的关系，以及首轮试用怎样辨认改善和退步。讨论精简程度、读取时机、案例保留的信息，以及反馈进入预设的条件。涉及具体平台机制时先创建并解决必要的官方文档研究议题。本议题形成接入方案，不直接修改全局配置。
