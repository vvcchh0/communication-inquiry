# 确定独立阅读与现场讲解的内容分工

Type: prototype
Labels: wayfinder:prototype

Blocked by: 02

## Question

同一个解释在独立阅读材料和有人讲解的演示中，关键关系应由正文、图示和讲者分别承担多少？

以已讨论的内容为基础制作小规模大纲或页面粗稿，决定哪些联系必须在交付物中可见、标题承担什么作用、何时需要保留完整段落。先选定一种关系进行比较，之后再判断因果、比较和谱系是否需要各自的案例。

## Comments

2026-11-03：用户认可按读者实际接触到的文字、图示和讲述整体安排理解路径。独立阅读材料保留必要背景、例子及关系；现场演示可由讲者补充，但需记录讲述内容以便比较。下一步建议以“无来由的反驳”为同一主题制作独立阅读短文和页面加讲稿的小样，保持核心主张及例子一致。原则已有认可，具体小样仍待比较。
