# 根据独立读者反馈确定背景与关系说明的取舍

## Question

未参与原会话的读者阅读小样后，哪些背景、例子和关系说明有助于建立理解，哪些仍需补充或可以简化？据此决定对外独立阅读材料如何组织。

## 发布与材料准备

本议题当前位于本地 tracker，尚未发布到外部平台。待阅读小样形成后，附上稳定版本和最少必要的阅读任务，再迁移发布。阅读任务说明材料想介绍什么，不提前给出预期评价或本会话分析结论。首次反馈前无需读者补读整个讨论。

## 参与方式

- 人类读者本人报告阅读体验与理解。Agent 不得代替读者作答、编造读者或将模拟反应写成真实反馈，也不得据自己的判断关闭本议题。
- Agent 可以单独标明身份，指出可能的理解跳跃，提出改写变体，或提供有来源的机构及组织案例；这些内容记为分析、候选材料或外部案例，不计为独立读者反馈。
- 使用 agent 帮助整理表达的读者，应确认整理结果忠实于自己的体验；保留原始反馈或明确哪些内容经过整理。
- 具体组织的案例附原始链接、受众、用途和讲述条件。效果证据另列，设计形式本身不作为有效性的证明。

## 给读者的反馈邀请

请先按自己的节奏读材料，再分享以下内容。可以自由叙述，无须逐项打分。

1. 你原先对这个主题熟悉到什么程度？
2. 用自己的话说说，你理解这份材料主要在解释什么，以及其中一个重要关系。
3. 哪个具体位置帮助你理解？哪里需要停下来补想、回读或仍然含糊？如果没有这样的地方，也请直接说明。
4. 阅读中有什么感受或疑问？有哪段内容让你想进一步探索？

若比较多个版本，记录先读哪版，尽量让不同读者交换阅读顺序。现场版需实际提供相应讲述或明确的替代方式，并注明阅读条件。

## 处理反馈

保留参与者原话及对应版本、阅读条件。区分理解复述、个人偏好和改写建议，保留分歧；据反馈提出修订，再请真人确认关键变化。少量反馈用于发现具体问题和形成修订依据，不外推普遍偏好。
