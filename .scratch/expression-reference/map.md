# 人的表达参考预设决策地图

Labels: wayfinder:map

## Destination

依据既有共识和完整实例的讨论，确定一套可供全局 AGENTS.md 路由的表达参考预设方案：明确适用场景、原则与案例的组织、使用方式以及试用反馈方式，使后续编写与接入有清楚依据。

## Notes

- 本轮规划承接用户已确认的[讨论共识](../../discussion-principles.md)和[会话记录](../../sessions/2026-11-02.md)，目的地来自此前约定的全局参考预设方向。
- 沿用 grilling 与 domain-modeling；集中提问只在建立框架或关键分岔时进行，日常讨论依反馈自然校正。
- Prototype 议题用少量粗稿支持比较与决定，按 prototype 技能推进。Research 议题仅在某个决定确实需要外部事实时创建，按 research 技能核验。
- 本地图以规划为主；讨论用粗稿属于决策材料。正式编写、修改全局配置和规模化测评在形成方案后另行安排。
- 采用本地 Markdown tracker。议题位于 issues/，按文件序号扫描 Status: open、未被未解决议题阻塞的文件；工作前置为 claimed，完成后追加 Answer 并置为 resolved。Blocked by 使用同目录议题编号；编号仅用于机器关系，人类阅读引用标题。
- 每轮处理一个需要用户参与的决策；保留原始案例和用户反馈，区分工作定义、偏好、事实判断与探索假设。
- 既有共识保留在原文件；本地图的 Decisions so far 仅索引此轮议题的解决记录。
